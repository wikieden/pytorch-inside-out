本章缩写：LN = LayerNorm（层 / 归一化）；RMS = Root Mean Square（均方根）；ReLU = Rectified Linear Unit（整流 / 线性 / 单元）；GELU = Gaussian Error Linear Unit（高斯 / 误差 / 线性 / 单元）；SiLU = Sigmoid Linear Unit（S 形 / 线性 / 单元，也叫 Swish）；GLU = Gated Linear Unit（门控 / 线性 / 单元）；SDPA = Scaled Dot-Product Attention（缩放 / 点积 / 注意力）；FFN = Feed-Forward Network（前馈 / 网络）；全部缩写见 附录 · 缩写与术语表

讲解

第一步：nn 与 F 的分工（2026-11-14）

同一个运算往往有两种写法：

torch.nn.X（类，模块） torch.nn.functional.x（函数）
nn.LayerNorm(d)：自带可训练的 weight、bias F.layer_norm(x, (d,), w, b)：参数自己传
nn.Dropout(p)：记得 train / eval 状态 F.dropout(x, p, training=...)：自己传
放进模型树、进 state_dict（第 7 章） 纯计算，没有状态

规矩：有参数或有状态的用 nn. 类，纯计算（激活、softmax、attention）用 F. 函数。

一句话：nn 是带参数和状态的模块，F 是纯函数；有参数用 nn，纯计算用 F。

第二步：LayerNorm 与 RMSNorm（2026-11-14）

目的：让每个 token 的向量"大小稳定"，层数叠很多也不会越算越大或越小（Transformer 第 19 章）。

LayerNorm：减均值、除标准差，再乘可学习的 \(\gamma\) 加 \(\beta\)：

\[\text{LN}(x) = \gamma \cdot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta\]

\(\mu\)（读"缪"）是均值，\(\sigma^2\) 是方差，\(\epsilon\)（读"艾普西隆"）是防止除零的小数。

RMSNorm：不减均值，只除以均方根，没有 \(\beta\)。少一次规约、少一个参数，效果差不多，Llama 以来的模型都用它：

\[\text{RMSNorm}(x) = \gamma \cdot \frac{x}{\sqrt{\frac{1}{d}\sum_i x_i^2 + \epsilon}}\]

数字演示：\(x = [1, 2, 3, 4]\)，\(\gamma = 1\)、\(\beta = 0\)：

中间量 结果
LayerNorm \(\mu = 2.5\)，\(\sigma^2 = 1.25\)，\(\sigma = 1.118\) \([-1.342, -0.447, 0.447, 1.342]\)
RMSNorm \(\frac{1 + 4 + 9 + 16}{4} = 7.5\)，\(\sqrt{7.5} = 2.739\) \([0.365, 0.730, 1.095, 1.461]\)

（实测 F.layer_norm 和 nn.RMSNorm(4) 输出一致。）LayerNorm 结果均值为 0；RMSNorm 结果不一定，但平方的平均是 1。

一句话：LayerNorm 减均值除标准差；RMSNorm 只除均方根，更省，现在的 LLM 默认用它。

第三步：激活函数与 SwiGLU（2026-11-14）

激活函数给网络加上"弯折"，不然多少层线性叠起来还是线性。

名字 公式 \(x = [-2, -0.5, 0, 1, 3]\) 的输出
ReLU \(\max(x, 0)\) [0, 0, 0, 1, 3]
GELU \(x \cdot \Phi(x)\)（\(\Phi\) 是标准正态的累积概率） [−0.046, −0.154, 0, 0.841, 2.996]
SiLU \(x \cdot \sigma(x)\)（\(\sigma\) 是 sigmoid） [−0.238, −0.189, 0, 0.731, 2.858]

GELU、SiLU 是"平滑版 ReLU"：负数不是一刀切成 0，而是留一点点；在 0 附近可导。

SwiGLU（现在 LLM 的 FFN 标配）：两条路，一条过 SiLU 当"门"，一条不过，逐元素相乘，再投影回去：

\[\text{FFN}(x) = W_2 \big(\text{SiLU}(x W_1) \odot (x W_3)\big)\]

\(\odot\) 读"逐元素乘"。PyTorch 里没有现成的 SwiGLU 层，就三行：

def swiglu(x, w1, w2, w3):
    return (F.silu(x @ w1) * (x @ w3)) @ w2

一句话：GELU / SiLU 是平滑的 ReLU；SwiGLU = SiLU 门 × 线性路，再投影，三个矩阵。

第四步：SDPA——一行 attention，背后自动挑最快的实现（2026-11-14）

自己写 attention（Transformer 第 9–17 章的公式）：

s = q @ k.transpose(-1, -2) / math.sqrt(d)              # 打分
s = s.masked_fill(causal_mask, float("-inf"))           # 因果遮挡
o = s.softmax(-1) @ v                                   # 加权

问题：中间的分数表 s 是 T × T 的。T = 8192 时，每个头一张表 6400 多万个数，写进显存再读出来，又慢又占地方。

用 SDPA：

o = F.scaled_dot_product_attention(q, k, v, is_causal=True)

（实测和手写版最大差 1.6 × 10⁻⁷，只是浮点舍入差。）它会根据设备、dtype、形状、有没有 mask，自动挑后端：

后端 特点
Flash（FlashAttention-2） 分块算、不写出 T × T 表，最快最省显存；要 fp16 / bf16
Memory-efficient（xFormers 那一派） 支持 float32 和更多 mask 形式
cuDNN 新 GPU 上 NVIDIA 的实现
Math 就是上面三行的参考实现，哪都能跑

可以用 with torch.nn.attention.sdpa_kernel(SDPBackend.FLASH_ATTENTION): 强制指定（指定的后端不支持当前输入时会报错，正好用来检查）。FlashAttention 原理见 CUDA 讲义第 22 章；第 29 章讲它为什么快（不写中间表 = 省显存流量）。

一句话：attention 用 SDPA 一行写，它自动选 Flash 等后端，不写出 T × T 分数表。

第五步：FlexAttention——想改 attention 又不想手写 kernel（2026-11-14）

研究里常要改 attention 的"打分规则"：滑动窗口、ALiBi 位置偏置、文档内因果（打包训练时不跨文档看）、前缀可双向……每种都手写一个 Flash kernel 太难。

FlexAttention：你只写一个小函数说明"分数怎么改"或"哪些位置能看"，PyTorch 用 torch.compile 把它编译进一个 FlashAttention 风格的 Triton kernel：

from torch.nn.attention.flex_attention import flex_attention, create_block_mask

def rel_bias(score, b, h, q_idx, kv_idx):        # score_mod：改分数
    return score + (kv_idx - q_idx) * 0.1

def causal(b, h, q_idx, kv_idx):                 # mask_mod：能不能看
    return q_idx >= kv_idx

block_mask = create_block_mask(causal, B=None, H=None, Q_LEN=T, KV_LEN=T)
o = torch.compile(flex_attention)(q, k, v, score_mod=rel_bias, block_mask=block_mask)

block_mask 还会记下哪些整块全被遮住，算的时候直接跳过（因果 mask 能省将近一半计算）。

本机实测的限制：Mac 上不编译直接调 flex_attention 能跑（会提示这是慢速参考实现，结果和手写版差 1.2 × 10⁻⁷）；torch.compile(flex_attention) 在 Mac CPU 上报"current platform is not supported"。它的主场是 CUDA GPU。

一句话：FlexAttention = 写一个改分数 / 定可见性的小函数，编译成 Flash 风格的 kernel；整块被遮住的直接跳过。

动画演示：手写 attention vs SDPA 的显存

可交互版：animations/14-attention-memory.html。滑块调序列长度 T。

怎么看：

  1. 左边手写版：Q、K 先算出完整的 T × T 分数表，写进显存，再 softmax、再乘 V；
  2. 右边 Flash 后端：一块块地算，分数表只在片上存一小块，用完就丢；
  3. 下方数字：T 从 1k 拖到 32k，手写版分数表大小按 T² 增长，Flash 版只按 T 增长。

数学原理

  • LayerNorm：\(\mu = \frac{1}{d}\sum x_i\)，\(\sigma^2 = \frac{1}{d}\sum (x_i - \mu)^2\)（PyTorch 用有偏方差，除以 d）。
  • GELU：\(x\Phi(x)\)；常用近似 \(0.5x(1 + \tanh[\sqrt{2/\pi}(x + 0.044715x^3)])\)（approximate="tanh"）。
  • SiLU：\(x \cdot \frac{1}{1 + e^{-x}}\)。
  • 分数表大小：\(B \times H \times T^2 \times\) 每个数的字节数。
