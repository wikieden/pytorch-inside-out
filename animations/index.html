跑起来看（按钮能动）

在仓库根目录的 Claude 会话里说"打开第 N 章动画"即可（.claude/launch.json 里的 pytorch-animations 配置）。自己在终端跑：

python3 -m http.server 8342 --directory pytorch-deep-dive/notes/animations

然后浏览器打开 http://localhost:8342/01-op-journey.html（换成想看的章节文件名）。

新增或修改一个动画

  1. 页面引用 anim.css 和 anim.js（从 transformer-deep-dive/notes/animations/ 复制来的同一套），提供 reset(seed) 和 next()（返回 false 表示播完），用 setupPlayer({captureSeed, reset, next}, 毫秒) 挂上播放按钮。
  2. 重新录 GIF（在本目录下执行）：

bash node ../../../tools/anim-capture/capture.mjs 01-op-journey.html 01-op-journey.gif 1600 # 第三个参数是每帧毫秒，取页面 setupPlayer 的间隔

录完删掉多出来的 *-last.png。 3. 在对应讲义的"讲解"末尾写 ### 动画演示，然后跑 python3 tools/gallery/build.py 和 tools/notes-sync/sync.sh pytorch-deep-dive "PyTorch"。
